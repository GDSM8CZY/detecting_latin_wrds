# Latin Dictionary
This will be a latin dictionary where you can search up any latin word and get english definitions, along with the part of speech, declension/conjugation, etc.

All definitions will be from [Dickinson College's Latin Core Vocabulary](https://dcc.dickinson.edu/latin-core-list1?order=field_display_headwords&sort=asc) for now.
